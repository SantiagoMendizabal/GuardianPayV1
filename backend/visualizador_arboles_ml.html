💡 Respuestas Clave para la Sustentación ante el Docente:

1. ¿Por qué en MySQL solo se ve 0 o 1?

MySQL es una base de datos transaccional (OLTP). Almacena las variables de entrada binarias (es_madrugada, es_contacto_nuevo) y la auditoría final. El cálculo de los 120 árboles ocurre en RAM a través del microservicio FastAPI en Python ejecutando random_forest_fraud.pkl.

2. ¿Cómo se calcula matemáticamente?

Random Forest no es una fórmula rígida; es un ensamble de votación mayoritaria. Cada árbol evalúa de forma independiente las 7 características y emite un voto (0 o 1). La función predict_proba() divide los votos de fraude entre 120: P = VotosFraude / 120.
